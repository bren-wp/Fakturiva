# Fakturiva — 20 referentnih ekrana / vizualni audit

**Izvor:** izvorni korisnikov arhiv s 20 PNG datoteka 1179×2556 te 20 *stvarnih* Android emulator screenshotova iz provjerenog v0.18.3-Android36 GitHub Actions artefakta (`42729397838`, `13725165052`). Ne koristiti dizajnerske reference kao navodne slike aplikacije.

**Napomena:** ovo je *baseline prije* promjena v0.18.4. Nema tvrdnje da je postignuto 0 % odstupanja; potreban je novi screenshot QA nakon builda i mjerljiva usporedba istim postupkom. MAE je prosječna apsolutna RGB razlika u rasponu 0–255; znak % u drugom stupcu označava udio piksela s bilo kojom RGB razlikom. Metrike obuhvaćaju Android statusne trake, datume, stvarne testne iznose, font rendering i grafiku. Za cilj 1:1 uspoređivati fiksne rezolucije, layout i komponente po ekranu, bez falsificiranja korisničkih podataka.

## Prioritet dorada

1. Tamna tema (#20): kartice, grafikoni, tipografija i kontrasti.
2. Izvještaji (#15): kartica prihoda i graf sada koriste **stvarno evidentirane uplate**, umjesto zbroja fakturiranih dokumenata; ponovno izmjeriti.
3. Početna (#04): hero KPI, veliki graf i kartice, nav bar, razmaci.
4. Pregled ponude (#11) i eRačun (#17): native tablice, akcije, dostupni elementi.
5. Prijava (#03): korisnikov novi uvjet *samo e-adresa i lozinka* ima prednost nad starom referencom koja je sadržavala alternativnu prijavu; zato pixel-perfect za zastarjelu sliku nije istovremeno moguća bez nove reference.

## Kriterij prihvaćanja

Usporediti svih 20 novonastalih snimki aplikacije iz **istog SHA/izdanja** s izvornim referencama kroz `quality/pixel_audit.py`, objaviti per-screen MAE/SSIM/diff te provesti accessibility i responsive provjere. 0 % nije utvrđeno niti ga se smije tvrditi bez mjerenja. Kod promjene funkcionalnog zahtjeva (uklonjen PIN/biometrija) nova, odobrena referenca prijave postaje mjerodavna.
