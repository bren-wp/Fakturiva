# Fakturiva v0.6 — vizualni postupak 20/20 ekrana

Referentni set: **Fakturiva_Android_Brending_i_20_Ekrana(5).zip**, 20 odvojenih PNG-ova veličine 1179×2556 px. Prethodno izmjerena odstupanja prikazana su u `docs/PIXEL_AUDIT.md`.

## Što je promijenjeno
- Native naplata: tri funkcionalna filtra, pravi iznosi i zasebni CSV izvoz uplata.
- Native pregled računa i ponude: stvarni ugrađeni Android PDF renderer, obračun, status i radne akcije.
- Tamna tema: nijanse pozadine i površina prilagođene uzorkovanim RGB vrijednostima originalnog PNG-a (13,23,40) i (20,35,59).
- Klijenti i tvrtke nastavljaju zadržavati stvarne poslovne podatke na povijesnim dokumentima.
- Validacija financijske integriteta baze i povratka kopije bez gubitka potvrđenih zapisa.

## Metodologija
GitHub Actions snima stvarne 1179×2556 emulatorske zaslone nakon izvođenja Android instrumentacijskih testova. Rezultate usporediti s originalima pomoću `quality/pixel_audit.py`. RGB MAE za novi build treba izmjeriti; **ne upisivati procijenjene ili izmišljene rezultate**. Posebno provjeriti ekrane 08, 11, 16 i 20, a zatim svih 20.

## Stvarna mobilna oprema
Test na fizičkim Android uređajima još nije izvršen unutar ovog okruženja. Potreban je autorizirani Android uređaj s USB debuggingom i `bash ci/test-physical-android-devices.sh`. Emulatorska provjera nije zamjena za fizičke uređaje.
