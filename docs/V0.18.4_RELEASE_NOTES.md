# Fakturiva v0.18.4-preview.1 — jedinstvena prijava i sigurnosna dorada

**Izdavač:** Brendigo · [fakturiva.eu](https://fakturiva.eu/) · **Android versionCode:** 24

## Što je promijenjeno

- Androidova i web registracija i prijava koriste **e-adresu i lozinku** (registracija traži i potvrdu). Uklonjeni su PIN dijalozi, stara numerička tipkovnica, biometrijska alternativa za prijavu te javna web PIN prijava.
- Postojeći Android profil s ranijim PIN-verifikatorom može se migrirati **tek nakon uspješne prijave istom e-adresom/korisničkim imenom i važećom lozinkom na HTTPS poslužitelju**. Identifikator profila i postojeći SQLite dokumenti ostaju, a pristup starim PIN-om više nije moguć. Za sigurnu migraciju potreban je pristup internetu; prije nadogradnje napravite sigurnosnu kopiju.
- Android za izvanmrežni pristup koristi isti e-mail i lozinku; lokalni verifikator ostaje zaštićen Android Keystore šifriranjem i derivacijom ključa. Sinkronizacijska lozinka osvježava se samo nakon provjerenog server logina i bez prepisivanja verzije podataka.
- Web osjetljive radnje zahtijevaju istu lozinku. Uklonjeni neiskorišteni server PIN-handleri, numerički JS/CSS i alternativni korisnički URL-ovi preusmjeravaju na prijavu.
- Izvještaji: graf i oznaka *Kretanje prihoda* temelje se na stvarno evidentiranim uplatama, ne na neplaćenim računima. Debug QA dodaje vlastite testne transakcije za reproduktivan prikaz.
- Ažurirani CI GitHub Actions, marketinški README, upute za hosting, audit dokumentacija i provjere e-mail/lozinka, backup/migracija.

## Paketi novog pretpregleda

GitHub Release workflow nakon prolaska provjera objavljuje Android debug APK, testni AAB, nepotpisani release AAB, Windows portable/setup, PHP web paket, source ZIP i SHA256SUMS. Stvarne snimke svih 20 zaslona ponovno se snimaju s instaliranog APK-a i osvježavaju u README galeriji.

## Ograničenja i sigurnosne napomene

**Nije potvrđeno 0 % odstupanja:** posljednja mjerena početna usporedba 20 zaslona odnosi se na prethodno v0.18.3 izdanje. Ovaj kod treba ponovno usporediti nakon novog builda. Web sučelje još nije puni dvosmjerni editor. Google Play produkcijski potpis, pravna usklađenost, stvarno funkcioniranje https://fakturiva.eu/ i certificirane eRačun/fiskalizacijske integracije nisu potvrđeni. Korisnik mora osigurati dostupnu šifriranu kopiju prije deinstalacije ili promjene lozinke.
