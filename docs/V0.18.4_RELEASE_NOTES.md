# Fakturiva v0.18.4-preview.1 — jedinstvena prijava i sigurnosna dorada

**Izdavač:** Brendigo · [fakturiva.eu](https://fakturiva.eu/) · **Android versionCode:** 24

## Što je promijenjeno

- Androidova i web registracija i prijava koriste **e-adresu i lozinku** (registracija traži i potvrdu). Uklonjeni su PIN dijalozi, stara numerička tipkovnica, biometrijska alternativa za prijavu te javna web PIN prijava.
- Postojeći Android profil s ranijim PIN-verifikatorom može se migrirati **tek nakon uspješne prijave istom e-adresom/korisničkim imenom i važećom lozinkom na HTTPS poslužitelju**. Identifikator profila i postojeći SQLite dokumenti ostaju, a pristup starim PIN-om više nije moguć. Za sigurnu migraciju potreban je pristup internetu; prije nadogradnje napravite sigurnosnu kopiju.
- Android za izvanmrežni pristup koristi isti e-mail i lozinku; lokalni verifikator ostaje zaštićen Android Keystore šifriranjem i derivacijom ključa. Sinkronizacijska lozinka osvježava se samo nakon provjerenog server logina i bez prepisivanja verzije podataka.
- Web osjetljive radnje zahtijevaju istu lozinku. Uklonjeni neiskorišteni server PIN-handleri, numerički JS/CSS i alternativni korisnički URL-ovi preusmjeravaju na prijavu.
- Izvještaji: graf i oznaka *Kretanje prihoda* temelje se na stvarno evidentiranim uplatama, ne na neplaćenim računima. Debug QA dodaje vlastite testne transakcije za reproduktivan prikaz.
- Ažurirani CI GitHub Actions, marketinški README, upute za hosting, audit dokumentacija i provjere e-mail/lozinka, backup/migracija.

## Dodatni prolaz v0.18.4 — stvarni grafovi i raspored početne

- Početna i tamna tema imaju prilagođene margine, visinu KPI kartice,
  linijski graf te razmake informativnih i brzih akcijskih kartica.
- Graf u KPI kartici koristi **ne-kumulativne vremenske segmente stvarno
  naplaćenih iznosa**, izračunate iz SQLite evidencije uplata; glatki
  prikaz može rasti i padati bez izmišljanja financijskih zapisa.

  ostaje dostupan drugim obračunima bez promjene.
- Opis usporedbe s prethodnim mjesecom prikazuje se samo kada postoji
  valjana osnovica, uz rezervni tekst o evidentiranim uplatama.

  na granicama testnih ekranâ 01/09/12, kako prikaz posebnog nacrta
  računa i ponude ne bi promijenio brojeve na kasnijoj Tamnoj temi.
  Nema resetiranja aplikacija na stvarnim uređajima.
- Dodani instrumentacijski testovi za vremenske segmente naplate,
  mjesečne granice, nulte uplate i očuvanje iznosa.

## Paketi novog pretpregleda

GitHub Release workflow nakon prolaska provjera objavljuje Android debug APK, testni AAB, nepotpisani release AAB, Windows portable/setup, PHP web paket, source ZIP, ZIP stvarnih snimki svih 20 zaslona i SHA256SUMS. Stvarne snimke nastaju iz instaliranog APK-a. README galerija ažurira se **isključivo kroz odobreni PR**, a release provjerava da snimljeni PNG-ovi odgovaraju prethodno pregledanim datotekama. Workflow ne radi commit ni push u `main`.

- Automatski provjerava verziju, već postojeće tagove i status pet obveznih CI workflowa za isti commit (Android, Android snimke, responsive, web/API sigurnost i Windows).

- Za zabranu izravnog rada na `main` potrebno je uključiti GitHub branch ruleset. Detalji su u [uputama za release-gate](RELEASE_WORKFLOW_GATES.md).

## Ograničenja i sigurnosne napomene
