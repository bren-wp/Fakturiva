# Fakturiva — sigurnosni i dead-code audit v0.18.4

**Opseg pregleda:** Android native Java / AndroidManifest / Gradle, PHP JSON API i web forme, CI i screenshot QA. Statička inventura koda nije dokaz potpunog penetracijskog testa. Validaciju stvarnog hostinga i Google Play Console nije moguće zamijeniti lokalnim/unit-testovima.

## Izvršene ciljane dorade

1. **Autentifikacija:** uklonjen korisnički PIN na Androidu i webu, uključujući zasebne ekran/tipkovnicu, URL-ove i javne PIN handler-e. Svi novi računi zahtijevaju e-mail i jaku lozinku; postojeća starija korisnička imena i dalje se mogu migrirati nakon provjerenog server password logina. Ne dodjeljuje se pristup drugoj SQLite bazi.
2. **Lokalna pohrana:** v2 provjera PBKDF2 sa saltom i AES-GCM Keystore zaštitom registra, ograničenjem pokušaja. Migracija zadržava postojeći profil ID, financijske zapise i backup. Prethodni 4–6 znamenkasti verifikator više nije prihvaćen za lokalnu prijavu. Osigurati backup i testirati migraciju na stvarnom starom profilu.
3. **Cloud revizija:** osvježavanje vjerodajnice samo za potvrđenu server sesiju, bez promjene `dirty`, `revision` i nepovezanih profila; prijenos šifrirane kopije ostaje preko HTTPS-a s kontrolnim zbrojem i optimističkim revizijama.
4. **Web:** osjetljive akcije za promjenu lozinke i brisanje zahtijevaju trenutnu lozinku; javne legacy PIN stranice preusmjeravaju na `login.php`. Izravno dostupni PIN JS i CSS uklonjeni. Endpointima `auth.php` ostaje CSRF i ograničenje veličine; `api.php` radi bearer i revizijsku kontrolu.
5. **Dead-code:** uklonjeni Android PIN screen, PIN tipkovnica, neiskorištena autentikacijska grana, stari PHP PIN login/link/validator, web numeric JS/CSS i dvije suvišne lokalne varijable u izvještajima.
6. **Snimke i financijska istinitost:** graf prihoda čita stvarne uplate. Lažni produkcijski računi i tvrdo zadane brojke nisu uvedeni; QA podatci unose se samo u izdvojeni debug emulator.

## Preostali značajni rizici / produkcijske prepreke

- **VISOK:** realni hosting `fakturiva.eu` — TLS, zaštita `/storage/` na Nginxu ili Apacheu, osiguranje server ključa i vanjski backup zahtijevaju provjeru na stvarnom deploymentu.
- **VISOK:** puna dvosmjerna sinkronizacija web/Android ne postoji; web trenutačno uglavnom čita potvrđeni šifrirani snapshot. Konflikt revizije i nepotvrđene offline izmjene zahtijevaju pažljivo rukovanje.
- **VISOK:** zamjena lozinke za već šifriran backup nije podržana bez sigurnog re-encryption postupka (trenutno server odbija promjenu). Korisnik mora sačuvati svoju lozinku i backup.
- **VISOK:** Google Play produkcija zahtijeva odgovarajući signing key, Play Console financijske deklaracije, Data safety, dostupnu i istinitu politiku privatnosti, brisanje računa, sigurnosnu provjeru te neovisnu fiskalizacijsku/eRačun provjeru.
- **SREDNJI:** neovisni test stare v1 lokalne PIN baze na fizičkim uređajima i u slučaju prekida mreže tijekom migracije. Ne brisati korisničke zapise kao automatski fallback.
- **SREDNJI:** transitive native dependency / printer SDK i 3rd-party SCA nisu potpuni bez zasebnog dependency lockfile/SBOM i skenera ranjivosti; svako ažuriranje zahtijeva test ispisa na SUNMI i generičkim uređajima.
- **SREDNJI:** puni vanjski penetracijski test, rate-limit abuse test i opterećenje više tenant računa nisu provedeni.
- **SREDNJI:** release kanal proizvodi debug-signed APK/AAB i nepotpisani release AAB, a ne valjani potpisani Play artefakt.

## Automatizirani release-gate

- Android: compile, lint, JUnit/test python pravila, instrumentacija, 20 stvarnih APK screenshotova, responsivna matrica (280–1280dp i landscape), audit JSON.
- Web: PHP lint, izolacija tenanta, HTTPS/CSRF, sesije, e-mail/password login/registracija, financijski snapshot, brisanje korisnika.
- Windows: setup/portable iz provjerenog .NET builda.
- Pregled mogućih mrtvih metoda iz `quality/code_security_audit.py` **kandidati su**, a ne automatski dokazi nedostupnog koda. Ručna provjera refleksije i JNI/manifest referenci obvezna je prije brisanja.

## Verzije i kompatibilnost

Android `compileSdk=36`, `targetSdk=36`, `minSdk=24`; Gradle 9.6, AGP 9.5, Java 17; AndroidX test runner 1.7.0 i SUNMI printerlibrary 1.0.24. GitHub Actions migrirane na Node 24 kompatibilne glavne verzije. **Nikakav audit nije garancija Play odobrenja ili odsutnosti svih grešaka.**
