# Fakturiva — autentična pixel usporedba (v0.10+)

Originalni ZIP `Fakturiva_Android_Brending_i_20_Ekrana(7).zip` sadrži 20 korisnikovih PNG referenci, a **ne** prikaze iz aplikacije. To nisu zamjenjivi izvori.

1. Na GitHub Actions izvršite **Verify native Android screens**, preuzmite artefakt `Fakturiva-Android36-real-screenshots` i raspakirajte ga tako da svih 20 PNG datoteka stoji u `captures/`.
2. Raspakirajte originalni korisnikov ZIP u `reference/`; mora postojati `reference/ekrani/` s 20 PNG-ova (1179×2556).
3. Na računalu s Pythonom 3.12 pokrenite:

```sh
python -m pip install -r quality/requirements.txt
python quality/pixel_audit.py reference/ekrani captures \
  --output build/visual/pixel_audit.csv \
  --summary build/visual/summary.json \
  --diff-dir build/visual/differences
```

Skripta mjeri **puni RGB MAE (0–255), SSIM (0–1), glavnu sadržajnu regiju, kanale R/G/B i udio različitih piksela**, sa SHA-256 ulaznih datoteka. Rezolucija mora biti potpuno identična. Mjerenje neće automatski biti proglašeno uspješnim samo zato što se izvršilo. Prvo provjerite ekran, tipkovnicu, navigacijske trake i stanje podataka.

`quality/test_pixel_audit.py` testira matematičku točnost alata na sintetičkim uzorcima, **ne** vizualnu sličnost same aplikacije.

Osnovica v0.9: 14,534/255 RGB MAE (20 ekrana). Dok novi screenshotovi i referentni ZIP nisu uspoređeni, v0.10 nema potvrđenu novu metriku.
