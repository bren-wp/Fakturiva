# Fakturiva v0.18.6-preview.1 — sigurnije web evidentiranje naplate

## Nova funkcionalnost
- Prijavom istom e-adresom i lozinkom kao Android, na `/business.php` može se evidentirati **stvarno primljena uplata** za već izdani račun, uz datum i način plaćanja (gotovina, banka, kartica ili ček).
- Server sam računa nepodmireni iznos iz spremljenih uplata; preplate, nacrti, nepostojeći računi, nevaljani datumi, prazni ili pogrešni iznosi i zastarjele revizije se odbijaju.
- Djelomična uplata čuva izvorni status računa; po potpunoj naplati status prelazi u `PAID`. Iznos računa, prethodne uplate, podaci izdavatelja, klijenti i stavke ostaju neizmijenjeni.
- Uplata se šifrira u potpuno istu FAK1 presliku kao i Android, s transakcijskim optimistic-CAS zapisom, poviješću i provjerom revizije. Windows WebView2 koristi isti web portal.
- Android odbija automatski/ručni pull tijekom nespremljenog nacrta, sukoba revizija, pauze ili lokalne izmjene, pa nepotvrđene podatke ne prepisuje server kopijom.
- Novi mobilni web kontrole i prošireni PHP/Python regresijski testovi. Android `versionCode 26` / `versionName 0.18.6-preview.1`.

## Siguran rollout
1. Prije server deploya sačuvajte `storage/data` i `storage/secret.php`, provjerite testirani restore i napredak revizija.
2. Najprije postavite verziju weba na testni HTTPS hosting, provjerite login/API `status/load/save`, uplatu i povrat na Android, zatim novu Android verziju.
3. Potvrdite ponovne prijave istim e-mailom i lozinkom za web/Android/Windows te testove stvarnog konflikta i nepotvrđenog offline unosa.
4. Spajanje i objava izdanja dopušteni su tek nakon zelenih finalnih CI testova i vizualne usporedbe originalnih referenci.

## Poznata ograničenja
- Ova nadogradnja **nije puni web editor za izdavanje i otkazivanje računa ili ponuda** i **nije automatski bezgubitni merge** paralelnih offline izmjena između uređaja. Statusi se prenose kao šifrirane revizije jedne baze.
- 20 Android QA screenshotova može se snimiti i usporediti, ali pixel-perfect `0 %` nije potvrđen bez izvornog skupa dizajnerskih PNG referenci i provjere na istom uređaju/densityju.
- GitHub objava nije deployment na `fakturiva.eu`. Server se mora zasebno postaviti i verificirati.
- GitHub preview APK je debug, AAB može biti debug-signed ili unsigned; **nije produkcijski Google Play potpis**. Za javnu Play objavu potreban je vlasnički release potpis i provjere.
