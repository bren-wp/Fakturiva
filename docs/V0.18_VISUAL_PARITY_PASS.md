# Fakturiva — targeted visual parity pass (dashboard and document preview)

Continuation from `8b52985a35` (v0.17.0-preview.1). No user data, document calculations, database migrations, invoices or PDF export paths are changed.

## Changes

- Use the licensed, original **Inter** typeface on native dashboard screens **04/20** and persisted document preview screens **08/11**, matching the reference design's named typeface. Preserve normal Android sans-serif on all other screens until their own measured iteration. Font is bundled locally; no runtime network request. On older devices where a variable font cannot load, text falls back safely to the original Android font.
- Remove the duplicate overflow action in the invoice/quote preview toolbar; the real, working contextual PDF menu remains in the status row and the bottom navigation still provides access to Settings.
- Keep live dates, saved client names, tax values and amounts. Do not hardcode reference screenshot data or add static screens.

## Required QA

1. Verify Android build, lint, instrumented tests and screenshot capture for the latest PR head.
2. Inspect **04/20** (light/dark dashboard) and **08/11** (invoice/quote) on Android 16; check font glyphs, quote header, proper working overflow menu, and no clipped amounts.
3. Run nine responsive emulator profiles, including 280 dp and enlarged text, plus tablet/landscape views.
4. Compare original **unaltered** 1179×2556 PNGs to the latest Android captures using `quality/pixel_audit.py` (MAE, SSIM and percent of differing pixels).
5. Do not report 1:1 or 0% pixel deviation without exact full-resolution verification. The original reference ZIP is not committed to the repository.
