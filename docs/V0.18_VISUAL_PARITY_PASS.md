## Implemented in PR #20

- **04 + 20:** local licensed Inter typography, matching the source `brending/boje_i_tipografija.json`; an accessible right chevron beside **Brze radnje** opens an actual functional list of shortcuts, without hardcoded business data. Preserve its previous vertical baseline.
- **15:** apply Inter only to this third-highest-deviation screen; replace the oversized month selector with a compact, width-constrained native calendar selector and keep a separate fully functional current-month pill. On narrow phones the selected month ellipsizes rather than colliding with the pill. Labels remain financially honest: "fakturirano" is not misrepresented as money received.
- **08 + 11:** align native typography to Inter; use the same small blue document mark in both real paper previews. **Both intentional original menus are preserved:** the toolbar overflow leads to Settings, while the smaller status-row overflow opens actual PDF actions. The original images show both menus, so removing one would itself violate 1:1.
- **Typography fallback:** Android sans-serif is used if an older device cannot load the bundled variable font; unrelated screens preserve their pre-existing typeface.
- No database schema, payment totals, legal notices, PDF generator, or saved user values were changed.
