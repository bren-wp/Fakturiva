# Fakturiva 0.18.1-preview.1 — pregledno izdanje

**Android · Windows · web | Autor: Brendigo | https://fakturiva.eu**

## Što je novo

- Usklađivanje stvarnih Android zaslona s 20 referentnih dizajna, posebno **Tamna tema, eRačuni, Početna, Stavke računa, Pregled ponude, Naplata, Računi, Ponude, Katalog i Prijava**. Izmjene ne znače automatski da je potvrđeno 0 % odstupanja.
- Poboljšan referentni prikaz ekrana **eRačuni**: naslov, ikonice, raspored, status informacijskog posrednika i navigacija na postavke.
- Android splash pri uobičajenom pokretanju ostaje prikazan **4,5 sekundi**.
- Poboljšana registracija i prijava web/Android s **e-adresom i lozinkom**, uz odvojeni lokalni PIN za Android. Postojeći korisnički računi mogu koristiti raniju PIN prijavu.
- Pohrana i oporavak preko verzionirane, šifrirane FAK1 kopije na istom HTTPS poslužiteljskom računu. Nema automatskog brisanja ili prepisivanja novijih server revizija.
- Dodatne provjere zaslona, funkcionalne regresije, sigurnosti i računa prema referentnim snimkama, kroz GitHub Actions.
- Marketinški README s **20 stvarnih screenshotova iz Android QA emulatora**, bez postavljanja vizualnih mockupova u ulogu stvarnih aplikacijskih snimki.

## Važne napomene

- Ova je verzija **preview**; nije službeno certificirano rješenje za hrvatsku fiskalizaciju i strukturirano slanje eRačuna.
- `DEBUG-SIGNED.aab` i `debug.apk` **nisu potpisani Google Play produkcijskim ključem**, a `UNSIGNED.aab` se mora potpisati odgovarajućim izdavačkim ključem.
- Web pregled trenutačno otključava posljednju potvrđenu poslovnu kopiju; **nije puni dvosmjerni web editor** svih poslovnih podataka.
- Izvoz i provjera korisničke sigurnosne kopije preporučuju se prije reinstalacije i nadogradnje. Nepotvrđene offline izmjene mogu se izgubiti.
- Izdanje se objavljuje samo nakon uspješne Android kompilacije, stvarnih 20 emulator screenshotova, instrumentiranih testova, PHP/API provjera i Windows izgradnje.
- Potrebno je pravilno produkcijsko HTTPS postavljanje `fakturiva.eu`, izvanjskog privatnog storage direktorija i odgovarajućih vjerodajnica za stvarne integracije.
