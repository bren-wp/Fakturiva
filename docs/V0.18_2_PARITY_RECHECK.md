## Native code changes in this PR

- **04/20 Home:** reduce excess vertical spacing above the greeting and hero; slightly compact the revenue graph and 2 KPI cards. All data, navigation, real month totals and colors remain intact.
- **08 Invoice preview:** reduce unnecessary paper padding and separators, preserving required issuer/buyer fields, amounts and footer while lifting the main confirmation button above bottom navigation.
- **11 Quote preview:** compress quote-specific padding and vertical separators on the paper, preserving all issuer/customer details and the full list of items, amounts and disclaimer. This should leave more room for PDF/share/convert actions on the first viewport. 08 invoice layout remains unaffected.
- **07 Invoice items:** remove the redundant inline back button only on screen 07 (original reference has no such inline control). The real native toolbar back arrow continues navigating to the first step; quotes retain their own back control.
- **15/16 Reports and Payments:** use the already-bundled native vector filter icon rather than a generic hamburger glyph, in line with the original top-right filter treatment.
- **16 Payments:** let long client names, document labels and payment amounts wrap or stack vertically on 280–320dp displays / at enlarged font scale, rather than overlap or silently elide currency totals.

All existing financial and backup functionality, local SQLite records, invoices and actual PDF export remain untouched. There are no new image mockups, external runtime dependencies or invented payment data.
