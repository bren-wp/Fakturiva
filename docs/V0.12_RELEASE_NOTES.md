# Fakturiva v0.12.0-preview.1 — Android pretpregled

**Brendigo · 7. studenoga 2026. · Android 7.0 ili noviji**

Fakturiva pomaže lokalno voditi poslovnu administraciju: račune, ponude, klijente, artikle i usluge, pregled naplate i PDF dokumente. Ovo izdanje detaljno dorađuje **tri uzastopna zaslona izrade računa**, bez gubitka postojećih funkcionalnosti i podataka.

## Novo u ovoj verziji

- **06 · Novi račun** — bliže poravnanje izvornom dizajnu, pravilniji položaj prikaza koraka i kompaktnija polja. Broj računa i dalje se dodjeljuje tek pri stvarnoj potvrdi; klijent se mora izričito odabrati.
- **07 · Stavke računa** — kompaktnije nativne kartice, čitljiviji iznosi i veća jasnoća pregledavanja. Uređivanje je dostupno dodirom kartice ili olovke; uklanjanje stavke preseljeno je u dijalog za uređivanje, s dodatnom potvrdom. Automatski izračun iznosa i PDV-a nije mijenjan.
- **08 · Pregled računa** — poravnati zaglavlje, okvir dokumenta i akcije, uz stvarni račun iz lokalnog SQLite spremišta i stvarno generirani PDF.
- **Responsivnost i pristupačnost** — zadržane provjere 20 stvarnih Android zaslona na devet profila (manji telefoni, veći font, tablet, pejzažni način); dodatna instrumentacijska i sigurnosna provjera prije objave.
- **Stvarni screenshotovi** — GitHub release workflow objavljuje novu galeriju snimljenu na Android emulatoru tek nakon uspješnog testa.

## Preuzimanja

- `Fakturiva-v0.12.0-preview.1-debug.apk` — za instalaciju i testiranje; debug potpis, nije produkcijsko Play izdanje.
- `Fakturiva-v0.12.0-preview.1-DEBUG-SIGNED.aab` — testni Android App Bundle s debug potpisom.
- `Fakturiva-v0.12.0-preview.1-UNSIGNED.aab` — nepotpisani AAB; za produkcijski Play upload potreban je odgovarajući ključ.
- `SHA256SUMS.txt` — kontrolni sažeci integriteta.

**Nadogradnja:** debug paketi ne jamče isti certifikat između izdanja. Prije uklanjanja ranije instalacije izvezite i provjerite šifriranu kopiju izvan telefona.

**Važno:** Fakturiva zasad ne obavlja fiskalizaciju niti slanje/primitak strukturiranih eRačuna. Prikazani PDF nije fiskalizirani ili strukturirani eRačun. Prije poslovne uporabe u takvim obveznim postupcima potrebno je implementirati i provjeriti zahtjeve važećih propisa.

**Vizualna podudarnost:** cilj je što vjerniji izvorni UI, ali nije dokazano 0 % odstupanja. Vrijednosti na stvarnom uređaju mogu se razlikovati od dizajnerske reference jer se prikazuju stvarni dokumenti i datumi; nema statičnih zamjena za radne kontrole.
