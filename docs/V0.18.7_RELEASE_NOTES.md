# Fakturiva v0.18.7-preview.1 — Android, Windows i web

## Implementacija
- Tipografija ostaje prilagođena pojedinim zaslonima: Inter se koristi na dashboardu, izvještajima i pregledu dokumenata, a drugi zasloni zadržavaju testirani sustavni font. Eksperiment s globalnim Interom povučen je jer je na stvarnim snimkama povećao RGB MAE s 8,0411 na 8,6426/255; ne prihvaćamo vizualne regresije radi deklarativnog fonta.
- Početna i tamna tema sada crtaju 12 stvarnih intervala evidentiranih mjesečnih SQLite uplata, umjesto kumulativnog prikaza koji samo raste. Iznosi, računi, porezi i stvarni korisnički zapisi se ne mijenjaju zbog dizajna.
- Android 16 screenshot QA odbija sistemski dijalog „Viewing full screen” kao dokaz aplikacijskog zaslona, ponovno provjerava stvarnu UI hijerarhiju i snimku te postavlja 09:41 u statusnoj traci **samo** na izoliranom QA emulatoru.
- Ručni HTTPS prijenos i automatsko slanje šifrirane FAK1 preslike serijalizirani su u jednonitnom redu; na prekidu Activityja ili neuspješnom ručnom prijenosu omogućena sinkronizacija se ponovno nastavlja. Za 409 konflikt i dalje vrijedi zaštita udaljene revizije bez tihog prepisivanja.
- PHP JSON API odbija neispravne tipove bez upozorenja koja bi kvarila odgovor; HTTP test koristi privremenu privatnu pohranu. Testirana logika naplate i integriteta ostaje neizmijenjena.

## Pixel-perfect test i dokaz
20 originalnih PNG referenci 1179 × 2556 px ostaje izvan repozitorija. Prethodna dokazana usporedba na merge commitu `815eada3d6`: **20/20 uspoređeno, prosječni RGB MAE 8,0411/255, nula potpuno identičnih zaslona**. Nova verzija mora proći ponovno snimanje i neovisnu usporedbu. **Ne tvrdi se pixel-perfect 1:1 dok svi stvarni pikseli svih 20 zaslona nisu jednaki.** Podaci iz maketa ilustrativni su i ne smiju zamijeniti stvarne financijske zapise.

## Paketi i ograničenja
- Android: debug APK, testnim ključem potpisani debug AAB i nepotpisani release AAB. **Nije potpisano produkcijskim Google Play ključem**.
- Windows: portable EXE i Setup EXE, ovisno o stvarnom Windows buildu.
- Web: PHP/JSON paket bez `storage/data`, serverovih ključeva i tajni; izvorni ZIP, stvarni emulator screenshotovi i SHA256SUMS.
- GitHub izdanje nije deployment na `fakturiva.eu`. Produkcijski Android–web–Windows E2E na stvarnim uređajima, certificirano slanje eRačuna i fiskalizacija nisu potvrđeni.
- Prije ažuriranja zaštitite i potvrdite vlastitu šifriranu sigurnosnu kopiju; izmjena certifikata može zahtijevati ponovnu instalaciju.

Automatska objava čeka Android build/lint/instrumentaciju, snimke 20 izvornih zaslona, deset responzivnih profila, PHP sigurnosne testove, Windows build i kontrolne SHA-256 otiske **na istom main commitu**. Prolazak tih provjera ne podrazumijeva automatsku identičnost svih referentnih piksela niti produkcijski sinkronizacijski E2E.
