# Fakturiva v0.18.3-preview.1 — Android, Windows i web

**Autor:** Brendigo · [fakturiva.eu](https://fakturiva.eu/) · **Android versionCode:** 23

## Novo u ovom izdanju

- **Ujednačena registracija:** API na poslužitelju prihvaća samo valjanu e-adresu za *nove* račune. Web i Android traže e-adresu, lozinku od najmanje 12 znakova i potvrdu lozinke pri registraciji. Prijava starijih računa s korisničkim imenom ostaje dostupna.
- **Android prijava i vraćanje:** neispravan lokalni PIN više ne zatvara dijalog i dopušta ispravak bez ponavljanja unosa web vjerodajnica. PIN je zaseban od web lozinke i ne šalje se poslužitelju.
- **Automatizirani test API-ja:** HTTP provjera potvrđuje da API odbija pokušaj registracije bez valjane e-adrese te da ispravan račun radi preko tokena i izoliranog prostora.
- **README / dokumentacija:** usklađeni opisi e-mail prijave, lokalnog PIN-a i granica web-integracije; automatizirani release QA ponovno snima stvarne ekrane instaliranog Android APK-a, a ne konceptne PNG reference.
- **Pouzdanije izdavanje:** workflow uzima bilješke za tekuću verziju, umjesto uvijek iz datoteke v0.18.2. Release se objavljuje tek kada prođu Android build, emulator, 20 snimki i pakiranje Windows i web izdanja.

## Distribucija

CI izdaje Android debug APK i testno potpisani AAB, nepotpisani release AAB, Windows portable/setup, PHP web paket, source ZIP i SHA256SUMS. Svi artefakti su **preview**. Produkcijski Play upload zahtijeva valjani izdavački ključ i provjeru produkcijskog hostinga.

## Ograničenja

20 izvornih PNG-ova su dizajnerske reference; prikazane slike README-a su snimke stvarno pokrenute aplikacije. **0 % vizualnog odstupanja nije potvrđeno.** Web i Android koriste isti server identitet, ali web još ne omogućuje istodobno dvosmjerno uređivanje svih dokumenata. eRačuni/fiskalizacija ostaju funkcionalnosti u razvoju, bez tvrdnje o certificiranom produkcijskom slanju. Udaljeni hosting https://fakturiva.eu/ potrebno je zasebno testirati.
