# Fakturiva v0.18.5-preview.1 — web i Android povezani kroz šifrirane revizije

## Novo
- **Web poslovni uređivač** `/business.php`: nakon prijave istom e-adresom i lozinkom kao Android, moguće je otključati poslovne podatke i uređivati profil tvrtke, klijente i artikle/usluge. Lozinka poslovnih podataka ne sprema se u PHP sesiju. Pregled i spremanje zahtijevaju ponovni unos, a povratne poruke prikazuju potvrđenu reviziju.
- **Stvaran povrat podataka na Android**: pri ulasku u postojeći povezani profil Android automatski provjerava ima li noviju potvrđenu server reviziju **prije otvaranja uređivača**. Aplikacija se ne sinkronizira automatski ako postoje lokalne promjene, aktivni sukob, radni nacrt, privremeno zaustavljen prijenos ili uključano zaključavanje uređaja. Za takve profile ostaje izričit korisnički postupak u postavkama.
- **Manja mrežna potrošnja**: autentificirani `status` API vraća reviziju, postojanje preslike i datum spremanja, ali ne šalje šifriranu bazu. Potpuni `load` radi se tek kada server ima novu reviziju. Stariji vlastiti serveri bez `status` akcije ostaju kompatibilni kroz postojeći autentificirani `load`.
- **Stroga zaštita promjena**: web i Android upisuju cijelu AES-256-GCM/PBKDF2 `FAK1` presliku pod istim atomskim zaključavanjem s `expected_revision` provjerom. Novi klijenti/kataloške stavke dobivaju nove stabilne ID-jeve; postojeći dokumenti, njihovi iznosi i povijesni izdavatelji ne mijenjaju se tim operacijama.
- **Usklađenost izvornog grafa**: početna i tamna tema sada crtaju kumulativni trend stvarno evidentiranih uplata, pa linija raste i slijedi izvornu vizualnu referencu, a ne mjesečne iznose odabranih pojedinačnih intervala.

## Instalacija i važan redoslijed
1. Izradite testiranu sigurnosnu kopiju cijelog server `storage/data` i `storage/secret.php`, uključujući povijest.
2. Na testnom HTTPS hostingu najprije postavite **novi `web/` paket** (PHP 8.1+, OpenSSL), bez brisanja postojećeg `storage` direktorija ili računa. Ako je glavna web stranica na drugačijem hostingu, provjerite da `fakturiva.eu/api.php` zaista upućuje na isti poslužitelj i da korisnici nisu preseljeni u drugu bazu.
3. Potvrdite registraciju, prijavu, `status/load/save`, transakcijski povrat, web spremanje tvrtke, klijenata i kataloga te pristup iz Windows WebView2 omotača.
4. Ažurirajte Android APK. Google Play za ovaj pretpregled zahtijeva **vaš produkcijski release potpis**, ne DEBUG-SIGNED ni UNSIGNED AAB.
5. Provjerite da web promjena postaje nova revizija i da se nakon nove prijave na Androidu preuzima samo u čist profil. Izvoz i provjera kod konflikta obvezni su prije ručne obnove.

## Kvaliteta i sigurnost
- PHP izolirani smoke: AES-GCM round-trip, sinkronizacija preko Android API tokena, CAS, historija, odvojenost računa, neizmijenjeni izdani dokumenti i integer-cent iznosi.
- Android: prethodni QA je potvrdio 20 stvarnih zaslona i prosječni RGB MAE **8,29/255** prema originalnim slikama prije ovog izdanja. Izvorne slike i dalje nisu javno pohranjene u GitHubu.
- Nakon nove korekcije grafa potrebno je ponovno izmjeriti svih 20 PNG zaslona i njihovu responsivnost. **Ne tvrditi 1:1** dok nijedan par ne pokazuje različite piksele.

## Granice
Ovo izdanje **nije puna višesmjerna CRUD/merge platforma**. Web podržava uređivanje tvrtke, klijenata i kataloga te pregled računa, ponuda i evidentiranih uplata iz posljednje potvrđene preslike. Android ostaje mjesto za izdavanje računa/ponuda, naplatu, PDF, ispis i druge transakcijske tokove. Paralelne izmjene dva uređaja ne spajaju se automatski; revizijski sukob zaustavlja spremanje kako se podatci ne bi izgubili. Windows je WebView2 omotač istog web portala, a ne zasebna poslovna SQLite baza.

Poslužitelj šifrirane preslike sprema na disk. Kod web uređivanja korisnikova lozinka i otključani podatci kratkotrajno postoje u PHP memoriji u okviru HTTPS zahtjeva; stoga ovo **nije zero-knowledge web editor** u odnosu na administratora samog servera. Ne spremati logove zahtjeva sa sadržajem lozinki. Nije potvrđena instalacija ili integracija na stvarnoj produkcijskoj domeni bez pristupa hostingu.

Izdanja uključuju DEBUG APK, DEBUG-SIGNED AAB, UNSIGNED AAB, Windows portable/setup/web pakete, stvarne screenshotove i SHA256SUMS; ništa od toga nije označeno kao produkcijski potpisani Play Store bundle.
