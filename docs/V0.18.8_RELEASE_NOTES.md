# Fakturiva v0.18.8-preview.1 — provjera trajnosti pohrane i izdanja

## Izmjene u ovoj iteraciji

- Web: šifrirani JSON zapisi i glavni ključ sada provjeravaju svaki zapisani bajt i rezultat `fflush`/`fsync` prije potvrđivanja. Kratki zapis i pogreška diska prekidaju operaciju; prethodno potvrđena datoteka ostaje netaknuta zahvaljujući atomskom `rename` postupku.
- Web QA: dodana izolirana provjera odbijenog zapisivanja na read-only stream uz provjeru da prethodno potvrđeni šifrirani podaci ostaju nepromijenjeni.
- Windows: verzija .NET klijenta i Inno Setup instalera usklađena je s Android verzijom `0.18.8-preview.1` (Android `versionCode 28`). Numeric Windows `VersionInfoVersion` zasebno je `0.18.8.0`.
- Izdavanje: dodan preventivni test usklađenosti verzija i provjera da je GitHub izdanje uistinu označeno `prerelease=true` te pokazuje na testirani SHA. Postojeći tagovi nisu izmijenjeni.
- Dokumentacija: README je ažuriran na potvrđenu usporedbu 20 zaslona iz PR-a #42 i poveznica za preuzimanja sada uključuje preview izdanja.

## QA, granice i obvezne provjere

CI mora proći Android build, instrumentaciju i stvarne snimke, 10 responzivnih profila, PHP security smoke te Windows build/installer na **istom završnom SHA** prije nove objave. Mjerljiva 1:1 podudarnost još nije ostvarena: zadnja potvrđena usporedba iz PR-a #42 pokazuje prosječni RGB MAE **8,003540/255** i **0/20** potpuno podudarnih zaslona. Nakon ove promjene nije izvršeno novo mjerenje originalnih privatnih referenci i nema tvrdnje o poboljšanom MAE/SSIM; [Issue #43](https://github.com/bren-wp/Fakturiva/issues/43) ostaje otvoren.

## Distribucija

- Android: stvarno izgrađen debug APK, debug potpisani AAB te zasebno nepotpisani release AAB. Potpis produkcijskim Google Play ključem **nije osiguran**.
- Windows: `Fakturiva-portable.exe`, `Fakturiva-setup.exe` i kompletan ZIP paket, uz ovisnost o WebView2 Runtimeu.
- Web: PHP/JSON paket bez podataka `storage/data` i bez `secret.php`, izvorni ZIP, stvarni screenshotovi, SHA-256 kontrolni zbrojevi.
- Nema potvrđene instalacije na `fakturiva.eu`, punog produkcijskog Android–web–Windows E2E-a, certificirane fiskalizacije ni strukturiranog eRačuna. Ne mijenjati stvarne podatke radi testova.

**Release smije nastati samo nakon uspješnih testova; ovaj dokument sam po sebi nije potvrda da je izdanje objavljeno.**
